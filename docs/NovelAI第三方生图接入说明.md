# NovelAI 官网、公益站和中转站生图

在「API设置 → 生图 → NovelAI」中启用功能。

1. 生图地址：填站点提供的API基础地址或完整生图地址，留空使用官网。
2. API Key：填该站点提供的Key。
3. 点击「拉取模型」，输入关键词搜索并选择；也可以手动填写完整模型名。
4. 点击「保存连接」，再进入「测试生成」。测试前也会保存当前连接，聊天随后使用同样的配置。

原有生成参数、全局画师串、角色专属提示词和绑定画风预设继续使用。画风预设不会替换生图地址和Key。

## 常见地址

| 服务 | 原生基础地址 | 模型列表 |
| --- | --- | --- |
| NovelAI官网 | `https://image.novelai.net` | 内置清单，也可手填官方型号 |
| Rinko NAI | `https://nai.rinko.ai/native` | 自动从该站 `/v1/models` 拉取 |
| Tale | `https://api.taleapi.asia/v1` | 自动从该站 `/v1/models` 拉取，需要Key |
| HamuBox | `https://api.hamubox.com/v1/novelai` | 自动从该站 `/v1/models` 拉取，需要Key |

以上为已核对公开文档的地址示例，不代表已用真实Key完成这些站点的出图验收。以站点最新说明为准。

## 高级连接设置

- 连接方式：自动模式优先使用NovelAI原生。站点明确要求「OpenAI Images」时选择「OpenAI图片兼容」；填写常见 `/images/generations` 完整路径也能自动识别。
- 地址填写方式：常见路径自动识别。站点给的完整地址使用特殊路径时，选择「完整地址」，避免附加路径。
- 模型列表地址：生图和模型清单路径不同、自动推导不适用时，填写站点提供的完整列表地址。
- 模型版本：站点使用自定义模型别名时，按站点说明选择V3、V4、V4.5或V5。模型名会完整发送，不移除分类前缀。
- 跨域代理范围：旧代理默认仅用于官网。自定义站点通常直接连接；确实需要代理时，在生成参数中配置代理，并调整范围。

## 使用提示

- 拉取模型只读取清单，不生成图片、不消耗生图额度。公开清单可在Key无效时仍然返回，因此拿到清单不等于生图连接成功。
- 重绘专用型号带有提示，不能直接用于聊天文生图。空清单或拉取失败不会清空当前选择。
- 各站点的模型列表分别缓存；切换站点后重新选择对应模型与Key。
- 未知的OpenAI图片兼容站只发送标准的模型、正面提示词、尺寸及单张图片请求；不声称步数、采样器、种子和负面词生效。需要完整NovelAI参数时，优先使用站点的原生入口。
- 支持ZIP、直接图片、常见JSON图片，以及SSE最终图片和长度前缀MessagePack流式最终图片。
- 超时不自动重复提交；先到站点查看记录，确认结果后再决定是否重试。
- 新配置同时保存到API配置记录，完整备份中的API配置可携带这些设置。Key属于私密信息，请妥善保管备份。
