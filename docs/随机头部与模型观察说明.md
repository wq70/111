# 随机头部与模型路由观察

在“设置 → AI行为”中找到“随机头部与宏规则”和“模型路由观察”。普通设置布局中也可直接找到这两个分组。两项总开关默认关闭，设置页点击“完成”后保存。

## 随机头部

在预设、世界书或提示词的首条启用条目里填写：

```text
{{random::晴天::微风::星夜}}
```

每次准备发送时随机选一个候选，允许连续抽到相同结果。可组合多个表达式，也支持嵌套和旧式 `{{random:甲,乙}}`。原条目、聊天记录和导出的原文不会被随机结果改写。生效范围可分别选择预设、世界书、提示词；提示词包括单聊、群聊、线下、心声及结构化总结。

关闭总开关后，可保留原文不解析，或不发送包含已知宏的整个条目。旧版整段提示词按一个条目处理，如只希望关闭头部，请把头部单独放成一个提示词条目。各自定义规则也可以独立停用并选择停用行为。

## 自定义宏

支持新增、编辑、排序、停用、预览及 JSON 导入导出。名称不区分大小写且不能重复，`random` 为保留名称。

- 固定文字：`{{greeting}}` 替换为规则内容。
- 随机候选：规则内容每行一个候选。
- 参数模板：规则内容 `你好，${1}` 配合 `{{greeting::朋友}}` 使用。
- 高级脚本：接收 `args` 参数数组和 `text` 原表达式，例如 `return args.join('-');`。脚本只返回文字，不读取应用状态；在独立来源的隔离页面和 Worker 中执行，禁止网络连接，超时会停止本次请求。

未知宏保留原文；宏返回的文字不会再次作为宏递归执行。导入只载入草稿，总开关及导入的高级脚本默认关闭，需自行启用并保存。这是自定义处理入口，不等于完整实现酒馆的变量存储、指令或插件系统。

“发送内容预览”按当前草稿及选择的来源运行，不保存设置、不调用模型。

## 模型路由观察

开启后，聊天标题下的“模型观察”和设置里的“最近的观察结果”展示请求模型、响应中的 `modelVersion` / `model` 及观察时间。支持普通响应、流式响应和工具调用多轮响应，每个聊天最多保留 20 条摘要，不增加 API 请求。

- 标识相同：接口报告一致。
- Gemini 系列不同，例如请求 Pro、返回 Flash：可能切换模型。
- 名称不同但无法确定系列变化：可能为版本、别名或路由差异。
- 接口没报告标识：无法判断。

所有结果都来自接口自报信息，不能证明上游实际采用的模型，也不能排除隐藏路由。不使用模型自我介绍或文风猜测模型身份。

实现语义参考 SillyTavern 官方 [宏文档](https://docs.sillytavern.app/usage/core-concepts/macros/) 和 [random 实现](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/scripts/macros/definitions/core-macros.js#L340)。随机头部是否影响具体服务的拒答或路由需要实际验证，不能保证效果。
