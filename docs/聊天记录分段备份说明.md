# 聊天记录按日期分段备份

单聊和群聊都从「聊天详情 → 导出聊天记录 → 按日期分段备份」进入。开始和结束日期包含当天，使用设备本地日期；清空两个日期可导出全部，包括没有时间戳的旧消息。

新备份只包含所选消息、消息中的本地照片和语音，以及这些消息引用的视频附件。不包含角色人设、API 设置、长期记忆或其他聊天。原有「完整备份 JSON」「TXT」「HTML」仍保留。外链照片、音频和视频保留原地址，不会重新下载，外部地址失效后无法保证继续播放。

文件按约 12 MB 自动分段，每份单独点击下载，不一次打包所有聊天。单条消息或一个视频本身超过目标大小时单独成份，不截断数据。请保存全部分段；文件名和内容带有备份批次及分段编号。浏览器显示开始下载后，请确认文件实际保存完成。

「导入聊天记录」支持新分段和旧的 EPhoneSingleChat JSON。先在目标单聊或群聊打开导入，预览新增及重复数量，再确认合并。分段可乱序导入；再次导入相同消息会跳过，内容不同的消息均保留。保存时重新读取最新聊天，消息和视频附件在同一数据库事务中写入，失败会一起回滚。

导入保留当前角色／群成员、聊天设置、既有消息及长期记忆。群聊备份不能导入单聊，反之亦然。跨群导入的历史成员保留原发言名，不按同名人物自动绑定或新增群成员。日期范围之外的被引用原消息不会自动补入。

## 验证

- `node --test tests/chat-history-transfer.test.js`：使用真实 Dexie 和隔离 IndexedDB，验证日期边界、分片、照片／语音／视频数据往返、乱序合并、重复去重、旧格式、群成员编号冲突、并发后保存及事务回滚。
- `node scripts/local-chat-history-preview.js`：本地独立示例页，默认 `http://127.0.0.1:8794/`。需要安装 Dexie 开发依赖，或通过 `HISTORY_TEST_DEPS` 指定包含 dexie 的目录；不读取生产数据库，也不调用模型。示例视频是字节占位，供备份数据核对，不供播放验收。
- `node scripts/build-index.js --check`、`node scripts/build-script-bundles.js --check`：校验页面及资源清单。
