# Fish Audio 语音接入

330 可以由浏览器直接连接 Fish，不需要用户部署后端。每位使用者填写自己的 Fish API Key；项目没有内置或共享测试密钥。

## 开始使用

1. 打开「API 设置 → Fish Audio 语音」，填写 Key，保留默认接口 `https://api.fish.audio`。
2. 默认模型为 `fish-audio/s2.1-pro-free`。点击「检查账户连接」和「生成试听」，成功后保存 API 设置。免费资格、额度和活动期限以 Fish 账户为准；不会自动切到付费模型。
3. 打开角色设置，将「语音服务」选为 Fish Audio。音色 ID 可留空使用默认音色，也可搜索公开音色、获取自己的私有音色，或粘贴 Fish 音色 ID / 分享链接。
4. 保存角色设置后，聊天语音和语音／视频通话使用该角色的 Fish 配置。

「获取模型」只读取公开模型目录，不能作为 Key 有效的证明。「检查账户连接」读取需要鉴权的账户接口，不生成音频。

## 已接入的能力

- 独立 Key、默认模型、通话模型、角色模型与自定义兼容网关；接受 Fish 常见兼容 API 根地址。
- 音色搜索、分页、公开／我的音色、详情、示例试听、音色收藏，以及 ID / 分享链接输入。
- 上传 1～20 段参考录音创建私有音色，修改自己的音色名称和简介，确认后删除自己的云端音色。未点击创建并确认前不会上传录音。
- 角色独立语速、表现力、多样性、音量、延迟模式、数字日期规范化、质量检查和声音参数预设。
- 高级参数支持参考音频、多说话人 ID、分块、重复惩罚、音量归一化、生成上限、MP3 采样率／码率、发音词典等。按照 [Fish TTS 参数说明](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech) 填写 JSON；上方语速和明确设置的声音参数优先。
- 情绪、笑声、停顿及说话人标签保留在合成文本里，效果由模型决定。语言选项用于文字规范化，不会强制改变音色口音。
- 聊天流式播放、完整音频回退、停止、长文本分段、双语朗读、临时缓存、音频保存、重新生成和下载。多段下载为 ZIP，单段为 MP3。
- API 预设、悬浮球配置、角色设置模板和原有备份链路包含新增 Fish 配置。参数预设不复制 API Key 到角色。

通话继续沿用现有顺序播放队列；「聊天流式播放」控制聊天语音条。浏览器不支持 MP3 流式播放或流式播放失败时，使用同一次请求收到的完整音频，不重新提交一次合成。

## 兼容已有 ElevenLabs 配置

### 使用中转站

「API 设置 → Fish Audio → 连接方式」提供「中转站 · OpenAI 兼容」和「中转站 · Fish 原生」。填写中转站自己的 Key、接口地址及其提供的模型原名，模型别名不会被自动添加 `fish-audio/` 前缀。

- OpenAI 兼容：例如 `https://中转域名/v1`，自动请求 `/v1/audio/speech`；也接受以 `/v1/audio/speech` 结尾的完整地址。
- Fish 原生：例如 `https://中转域名` 或以 `/v1/tts` 结尾的地址，使用原生 JSON 及 `model` 请求头。
- 特殊路径：在「完整合成地址」填写完整 URL，直接使用该路径和查询参数，不再拼接。模型获取、转写仍按「接口地址」请求。
- 可选「音色管理地址」仅用于 Fish 原生音色管理接口，共用当前中转 Key；留空跟随中转站，不会自动把中转 Key 发给官网。

仅提供合成的中转站可跳过获取模型和音色，直接手填模型、音色 ID 并试听。目录检查只能证明对应接口可访问，鉴权和合成支持通过试听确认。音色增删改、转写与高级 Fish 扩展参数取决于中转站支持情况。网页直连要求中转站允许跨域；Fish 原生格式还需允许 `model` 请求头。尚未对某家具体中转站进行真实账户测试。

### ElevenLabs 中的 Fish 兼容地址

如果 ElevenLabs 接口地址为 `https://api.fish.audio/compat/elevenlabs`，330 会识别为 Fish，转换到浏览器可直连的兼容合成接口，并使用该 ElevenLabs 配置中填写的 Fish Key、Fish 音色 ID 和模型。

支持语速及稳定度映射；相似度、风格强度和声音增强不会被冒充为有效 Fish 参数。需要完整 Fish 参数时，请使用独立 Fish 服务。真正的 ElevenLabs 接口及其他 ElevenLabs 网关保持原有请求方式。

## 录音转文字

在角色的真实语音设置中，将「角色理解方式」或「电话理解方式」选为「Fish 转文字」。它复用 API 设置中已经保存的 Fish Key，默认转写模型为 `fish-audio/transcribe-1`，不需要把 Key 复制到角色里。

转写使用 Fish 的浏览器兼容转写接口，独立计费，不随免费 TTS 模型自动启用。失败时保留录音和已有识别结果，可手动补充文字或发送原声。[Fish 兼容接口说明](https://docs.fish.audio/developer-guide/compat/capabilities)

## 需要后端或官网的部分

正常合成、播放、音色搜索和已开放跨域的音色管理使用用户自己的 Key 直连即可。

若要给所有人共享一个隐藏的作者 Key、在服务器统一管理额度，或访问没有开放跨域的原生接口，则需要受控后端。音色发布、声音设计等可使用 [Fish 官网](https://fish.audio/app/)。本次聊天播放采用 HTTP 音频流，没有接入 WebSocket 实时会话和逐字时间戳接口，也没有把 Fish 的音乐、音效、变声等独立产品算作已完成的语音合成能力。

聊天播放和下载统一请求 MP3，以复用现有播放器及移动端回退；没有提供裸 PCM、WAV、Opus 的独立导出工具。

## 验证范围（2026-11-01）

使用已授权的测试账户和免费模型，在 Edge 的隔离页面加载项目正式脚本与 HTML 片段，实际验证：账户鉴权、模型获取、公开音色列表、试听完成、参数保存／重载、聊天流式播放完成、通话朗读完成、不支持流式时同一请求回退播放、MP3 下载及下载不重新合成。

正式聊天流式音频 72,306 字节、播放约 4.52 秒；通话和回退分别返回 38,451 字节、播放约 2.40 秒。流式播放在音频接收完成前开始。实际下载文件非空，回退下载没有新增合成请求。

另外验证了窄屏布局和自动化回归。完整应用的本地首次入口停留在原有账号登录页，本次使用隔离页面验证语音组件，没有绕过登录或改动原聊天数据。

苹果、安卓真机未验证；浏览器窄屏检查不能代替真机。私有音色创建／修改／删除与 Fish 转写已做请求和状态流程测试，但未上传用户真实录音或执行云端删除，也未调用付费转写来冒充免费实测。多说话人、内联参考音频、发音词典等高级参数已接入并验证请求结构，未逐项进行真实计费合成。

测试 Key 没有内嵌在项目代码、静态页面或预设中，免费资格失效或 Key 过期后会显示错误，不会自动充值、换 Key 或改用付费模型。
