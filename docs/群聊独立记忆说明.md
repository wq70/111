# 群聊独立记忆

入口：群聊设置 → 群聊记忆归属。

- 旧群继续使用原有共享模式。每个群可以分别选择共享或独立。
- 独立模式按群和成员 ID 保存记忆。同名角色不会共用一个档案，不同群互不读取，也不写回角色私聊。
- 日记式、结构化和向量模式分别保留数据与总结进度，切换模式不自动合并。
- 其他聊天的挂载记忆默认为「严格隔离」。可以主动选择允许例外，仅读取明确挂载的来源；本群不会因此成为其他聊天可读取的来源，其他独立群仍保持隔离。
- NPC 默认不生成记忆，可以在设置中逐个勾选。关闭后不参与总结和读取，已有记忆保留。
- 首次开启独立模式从之后的新消息开始积累。可以进入「管理本群独立记忆／补建旧记录」，选择消息范围及成员补建旧记录。每位成员每批调用一次已配置的主／副 API，向量模式按现有配置调用向量接口，无向量接口时沿用本地检索。
- 任务失败或停止时，已完成批次保留；手动重试跳过已处理消息。失败后暂停自动总结，避免后台反复重发。
- 管理页可以查看、添加、编辑、删除成员记忆，并导入、导出整个群的独立记忆。完整聊天备份、记忆分类备份及记忆存档均保留群独立记忆。
- 切回共享模式保留独立档案。清空聊天并选择一并清除记忆时，独立模式只清除本群独立记忆。

开启独立模式不会自动清理过去在共享模式下已经写入私聊的记忆，也不会删除原群聊历史。

本地验收：运行 `node scripts/local-group-memory-preview.js`，打开终端显示的本地地址。页面使用独立示例数据及模拟模型，不读取真实聊天，不产生真实模型费用。
