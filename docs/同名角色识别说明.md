# 同名角色识别

同名角色各自保留独立身份。角色本名和备注可以相同；动态、评论、点赞、群内发言以及跨聊天投递使用角色 ID 区分。

在「聊天详情」的基础信息中，可以给角色填写可选的「角色区分标签」，例如「校园线」「成年线」。标签显示在聊天列表、联系人选择、动态以及角色选择窗口中，不替代角色本名，也不表示共享记忆。普通聊天设置模板不复制身份标签。

旧评论没有身份信息且存在同名候选时，显示「身份待确认」。点击回复，选择这条评论属于哪位；选择仅保存到这条评论。取消不会改写旧记录。已保存的归属在改备注和重开页面后仍然有效。

前台生成或编辑回复时，如果模型没有给出可确定的身份，会提示选择。取消编辑中的身份选择会保留原回复。后台动作遇到无法确定的身份时跳过该动作，不自动选择第一个同名角色。

已有 ID 的记录不会因角色被删除而自动改归其他同名角色。旧数据不会整批自动重分配，也不会自动把同名角色当成同一个人。

验证覆盖同名与同备注、用户与角色同名、NPC 同名、同名群聊、实际私信/跨群/动态/评论分支、通知目标、取消、改备注与保存重开。浏览器测试使用独立的临时数据，不读写真实聊天。
