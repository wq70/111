# 向量记忆统一 API

在总 API 设置的「AI 功能」分类中找到「向量记忆 API（全局）」，开启「启用统一向量接口」，填写地址、API Key 和支持 Embedding 的模型，点击右上角「完成」保存。可先拉取模型或测试接口；这两个操作会发起请求，但不会保存配置或处理旧记忆。

角色的「变量记忆 → 极客设置 → 向量记忆 API」提供三种来源：

- **跟随全局设置**：全局启用后共用此接口；全局关闭时沿用原有副 / 主 API 地址和 Key，模型为 `text-embedding-3-small`。
- **此角色单独配置**：优先使用角色原有地址、Key 和模型，不受全局设置影响。沿用原有兼容规则：独立 Key 留空使用主 API Key；独立地址留空使用副 / 主 API。
- **使用原有默认方式**：始终使用原有副 / 主 API，不跟随全局向量设置。

新全局开关默认关闭。旧角色已经开启的独立配置保持优先；没有独立配置的角色默认跟随全局。切换来源会保留已填写的独立接口，便于切回。

共用的是接口，各角色记忆仍然独立。聊天模型、总结模型、提取规则和记忆模式保持原样。全局 Key 单独填写，不自动借用主 API Key。

保存或修改统一配置不会自动重建已有向量。更换接口、模型名称或配置来源时，如果角色已有向量，会让你选择：

- **沿用已有向量**：确认底层模型相同，只是更换地址或分类前缀时使用。不重新向量化，不额外请求接口。
- **作为新模型使用**：保留旧模型的向量，新模型单独生成，不覆盖旧套。
- **恢复此配置以前保存的向量**：切回旧配置时直接恢复对应结果，内容未变的记忆不需要重建。
- **取消切换**：保留原配置和向量。

全局设置中，同一次接口变化影响的角色共用一次选择；独立配置的角色保持原接口。API 预设、副 API 预设和悬浮球切换也遵循相同规则。

角色设置中的「选择已有向量」可恢复此前已被标为 BM25 的旧向量，无须重新填回旧接口。若选择沿用后发现向量维度不匹配，会明确提示并保留旧数据，不进行语义混算；可以点击「作为新模型使用」，再手动重建。维度相同不等于底层模型一定相同，是否沿用由你确认。

点击「补全/重建向量」才会请求接口并消耗额度。成功结果逐条保存，可随时点击「停止重建（保留进度）」。刷新后再次开始，只处理当前模型仍缺少或内容已变化的记忆，已经成功的部分不会重复请求。失败项可以重试；旧模型向量始终保留。修改记忆正文或标签后，旧内容的向量不会被当作新内容继续使用。

正在提取、整合、补全或重建时，请先结束当前记忆任务再切换配置，避免并发任务覆盖数据。多模型向量及沿用关系随完整备份、完整记忆导出和选中记忆导出保留。

全局配置随完整数据备份保存和恢复，不随聊天 API 预设切换。单独导出角色的向量记忆不会带出全局 Key，导入角色记忆也不会覆盖全局设置。
