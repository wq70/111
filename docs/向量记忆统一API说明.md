# 向量记忆统一 API

在总 API 设置的「AI 功能」分类中找到「向量记忆 API（全局）」，开启「启用统一向量接口」，填写地址、API Key 和支持 Embedding 的模型，点击右上角「完成」保存。可先拉取模型或测试接口；这两个操作会发起请求，但不会保存配置或处理旧记忆。

角色的「变量记忆 → 极客设置 → 向量记忆 API」提供三种来源：

- **跟随全局设置**：全局启用后共用此接口；全局关闭时沿用原有副 / 主 API 地址和 Key，模型为 `text-embedding-3-small`。
- **此角色单独配置**：优先使用角色原有地址、Key 和模型，不受全局设置影响。沿用原有兼容规则：独立 Key 留空使用主 API Key；独立地址留空使用副 / 主 API。
- **使用原有默认方式**：始终使用原有副 / 主 API，不跟随全局向量设置。

新全局开关默认关闭。旧角色已经开启的独立配置保持优先；没有独立配置的角色默认跟随全局。切换来源会保留已填写的独立接口，便于切回。

共用的是接口，各角色记忆仍然独立。聊天模型、总结模型、提取规则和记忆模式保持原样。全局 Key 单独填写，不自动借用主 API Key。

保存或修改统一配置不会自动重建已有向量。更换接口或模型后，不兼容的旧向量停止参与语义计算，记忆正文和旧向量保留，仍可按关键词检索；需要时在角色设置中手动点击「补全/重建向量」。重建会消耗接口额度。重建或整合期间更换模型会停止当前处理，避免混用模型结果。

全局配置随完整数据备份保存和恢复，不随聊天 API 预设切换。单独导出角色的向量记忆不会带出全局 Key，导入角色记忆也不会覆盖全局设置。
