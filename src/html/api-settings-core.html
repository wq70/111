接口与通话设置

填写中转站的地址、Key 和模型原名，模型名会原样发送。OpenAI 格式自动接 /v1/audio/speech，Fish 原生格式接 /v1/tts；路径特殊时填写完整合成地址，将直接使用该地址及查询参数。

音色列表、音色管理、模型目录和转写是否可用，取决于中转站开放了哪些接口；不支持音色列表时可以手填音色 ID。管理地址使用同一个中转 Key，默认不会转发到官网。高级声音参数需要中转站支持 Fish 扩展。浏览器直连还需要中转站允许跨域，Fish 原生格式需允许 model 请求头。

录音和通话的理解方式可单独选“Fish 转文字”，使用这里的 Key。转写独立计费，不随免费合成模型自动开启。

默认直接连接 Fish，使用允许浏览器跨域的音频接口，无需部署后端。也接受以 /compat/v1 结尾的地址。自定义网关需支持相同接口和跨域。

已有 ElevenLabs 配置若填写 Fish 官方 /compat/elevenlabs 地址，也会自动使用可直连的 Fish 请求；更多 Fish 参数请切换到独立 Fish 服务。
