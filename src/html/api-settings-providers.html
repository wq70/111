群聊提示词：用于群聊场景（有用户参与）。下方显示的是完整的默认提示词，你可以直接修改。
单人线下模式提示词：用于单人线下剧情模式。下方显示的是完整的默认提示词，你可以直接修改。
群聊线下模式提示词：用于群聊线下剧情模式。下方显示的是完整的默认提示词，你可以直接修改。
